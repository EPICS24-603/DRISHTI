# DRISHTI v0.0.1 — Initial Release

> **EPICS Group 603 • VIT BHOPAL**

## What is DRISHTI?

DRISHTI is an AI-powered Android accessibility app for the visually impaired, built as an EPICS (Engineering Projects In Community Service) project at VIT Bhopal.

---

## 3 Accessibility Modes

| Mode | Description |
| ------ | ------------- |
| 🎥 **AI Navigation** | Real-time camera obstacle & hazard detection with spoken directional guidance |
| 🎙️ **AI Voice Assistant** | Ask questions by voice about your surroundings — answer spoken aloud |
| 📖 **Read Text Aloud** | Point camera at signs, labels, documents — text read aloud via OCR |

---

## v0.0.1 Highlights

- Gemini 2.5 Flash-Lite for fast navigation (< 1 second response)
- Gemini 2.5 Flash for high-accuracy OCR and conversational Q&A
- Smart motion detection — skips API calls when camera is stationary (saves ~70% tokens)
- In-app API key management (Settings screen — no hardcoding)
- Configurable navigation speed (2.5s / 3.5s / 5s cadence)
- EPICS Group 603 team credits in app
- CameraX + SpeechRecognizer + TextToSpeech fully integrated
- Min Android 11 (API 30), Target Android 15 (API 35)

### Installation Steps:
1. Click the download link above on your Android device (or transfer the APK via USB/Drive).
2. Enable **"Install from unknown sources"** in your Android Settings if prompted.
3. Open `DRISHTI-v0.0.1.apk` and tap **Install**.
4. Launch DRISHTI, tap the **Settings** icon in the top right, and paste your Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey).

> ⚠️ Requires Android 11+ (API 30+) and a Gemini API key.
